Horned Knight Recreation

Custom-Engine C++ Singleplayer

This is one of my first games in C++, it is a recreation of one level from the Nitendo game Horned Knight. The game is using a custom engine which wasn't made by me.

Features

  • Enemy AI
  • Static or dynamic traps
  • 2D Platformer movement mechanics

Technical Challenges

The main technical challenge of this project was to implement a 2D platformer movement system that felt responsive and fun to play in a custom very simplistic engine in C++. Also the implementation of the custom particle system proved to be a challenge as well.
